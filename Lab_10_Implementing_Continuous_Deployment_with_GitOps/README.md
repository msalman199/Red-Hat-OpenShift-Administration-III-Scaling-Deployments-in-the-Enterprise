## 🔑 Key Concepts

| Concept | Description |
|---|---|
| **GitOps Pipeline** | An end-to-end deployment workflow where Git commits drive automated, reconciled changes to a running cluster |
| **ArgoCD (Argo CD)** | A declarative GitOps continuous delivery tool for Kubernetes/OpenShift |
| **Single Source of Truth** | The principle that Git holds the authoritative record of what should be running in the cluster |
| **Automated Deployment Workflow** | A pipeline that triggers and applies deployments automatically in response to Git repository changes |
| **Application Rollback** | Reverting a deployment to a previous Git-tracked state to recover from a problematic release |
| **Kustomize Overlays** | Environment-specific configuration layers applied on top of a shared base to manage multiple deployment environments |
| **Audit Trail** | The historical record of changes in Git used for security review and controlled access |
| **Production-Readiness** | Security and monitoring practices applied to a GitOps implementation to support enterprise, large-scale use |
